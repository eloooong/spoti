# SpotiStats Tasteprint S

Approved artwork: Tasteprint with an S signature from `design/logo-concepts/round-03/`.
The original Tasteprint arch and dot surround a custom rounded S.

- `spotistats-logo.svg`: green symbol and off-white outlined wordmark, for the dark site header.
- `spotistats-symbol.svg`: standalone green symbol, for small brand accents.
- `../favicon.svg` and `../favicon.ico`: dark symbol on a green tile, for browser tabs.
- `../apple-touch-icon.png`: 180px touch icon.

Keep the artwork proportional. Maintain clear space of at least one outer band width (32 units on the 256-unit canvas) around the visible symbol. Use the full lockup at the header's current 156px image width or larger; use the standalone symbol when space is smaller. The symbol has been reviewed at 16, 24, 32 and 64px in black and reversed white. The outer silhouette and dot remain recognizable at 16px; prefer at least 24px when the inset S must read clearly. The favicon uses a green tile for contrast.

Colors: green `#1ed760`, dark ink `#111812`, and off-white `#f3f5f3`. Use the light wordmark on a dark background and the dark symbol on the bright green tile. Avoid white on bright green.

Lettering is outlined Manrope 650, under SIL OFL 1.1. The license is retained at `design/logo-concepts/Manrope-OFL.txt`. SVG files need no font installation.

The approved files are committed. To regenerate these web assets from the source, install the optional design dependencies `resvg-py` and `Pillow`, then run `python design/logo-concepts/publish_brand.py` from the repository root. They are not required to build or run the website.
